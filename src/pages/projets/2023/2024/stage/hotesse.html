Web Stage en entreprise 3D

Hôtesse

Juin 2024 - Juillet 2024

Développement d'une application d'accueil interactive destinée aux bornes tactiles à l'entrée d'un bâtiment.
Elle permet de visualiser des contenus vidéo, de naviguer au sein d'une carte 3D interactive et d'orienter les visiteurs.
Ces derniers peuvent rechercher un collaborateur ou sélectionner un bureau pour consulter la liste des occupants et le trajet à suivre.
Une interface d'administration dédiée permet de gérer et de mettre à jour en temps réel l'annuaire ainsi que les médias diffusés.

Technologies & Outils

HTML/CSS JavaScript PHP Three.js C# PowerBuilder SQL Server IIS

Détails

  • Développement de trois applications interconnectées :
    • Application web embarquant la carte 3D interactive
    • Application C# orchestrant le lancement des vidéos et de l'interface web
    • Application PowerBuilder dédiée au paramétrage et à l'administration de l'écosystème
  • Conception et interconnexion d'une base de données centralisée
  • Mise en place et animation de réunions client en autonomie (suivi de l'avancement et intégration des retours)
  • Déploiement et hébergement de l'application web sur un serveur interne Windows avec IIS

  • Hard Skills valorisés : Gestion de base de données, UI/UX Design, Administration système
  • Soft Skills valorisés : Autonomie, Communication relationnelle
