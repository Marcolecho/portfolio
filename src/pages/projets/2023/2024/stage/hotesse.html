Web Stage entreprise 3D

Hôtesse

Juin 2024 - Juillet 2024

Application à l'entrée d'un bâtiment sur un grand écran tactile
Visualiser des vidéos ou naviguer dans une carte 3D du bâtiment
Rechercher une personne ou sélectionner un bureau pour donner le chemin à parcourir et les gens présents dans le bureau
Application de gestion permettant de mettre à jour les vidéos et les personnes dans les bureaux

Technologies & Outils

HTML/CSS Javascript PHP Three.js C# PowerBuilder SQL Server IIS

Détails

  • Réalisation de trois applications différentes travaillant ensemble :
    • Application web contenant la carte 3D
    • Application C# permettant de lancer diverses vidéos et l'application web
    • Application PowerBuilder permettant de paramétrer les deux applications
  • Base de données connecté aux projets
  • Réunions clients en autonomie pour faire suivre l'avancement et prendre en compte les retours
  • Mise en ligne de la carte 3D sur un serveur windows interne avec IIS

  • Hard Skills valorisés : Base de données, UI/UX
  • Soft Skills valorisés : Autonomie, Communication
