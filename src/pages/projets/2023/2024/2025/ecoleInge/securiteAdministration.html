Projet Ecole Sécurité Administration

Sécurité & Administration

Novembre 2024 - Décembre 2024

Dans le cadre d'un projet école, nous avions à protéger un système d'information d'une potentielle future attaque.
Les objectifs de ce projet étaient de tout d'abord reproduire l'architecture du systeme d'information avec plusieurs machines virtuelles puis de mettre en place un active directory propre et hiérarchisé ainsi qu'un ERP.
Nous devions aussi créer une politique de sauvegarde, de filtrage, une cartographie du système d'information (Administrative/logique/physique).

Technologies & Outils

VM ware Cisco packet tracer Pfsense Windows server Ubuntu Docker

Détails

  • Prise en main d'active directory
  • Mise en place à d'un ERP
    • Serveur fronEnd Windows server avec IIS
    • Serveur backEnd Ubuntu avec docker pour la gestion des bases de données
  • Firewall pfsense
  • Proxy squid
  • Sauvegarde 3-2-1 et RAID

  • Hard Skills valorisés : Sécurité, Administration, Réseau
  • Soft Skills valorisés : Travail d'équipe, Communication, Vulgarisation, Gestion de projets
