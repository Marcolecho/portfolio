Projet École Sécurité Administration

Sécurité & Administration

Novembre 2024 - Décembre 2024

Projet d'ingénierie réseaux axé sur la prévention et la sécurisation globale d'un système d'information face aux menaces cyber.
L'objectif consistait à modéliser l'infrastructure complète à l'aide de machines virtuelles, puis à déployer un annuaire Active Directory hiérarchisé ainsi qu'un ERP d'entreprise.
Le projet intégrait également la définition d'une stratégie de sauvegarde rigoureuse, la configuration du filtrage réseau et la réalisation d'une cartographie multidimensionnelle (administrative, logique et physique).

Technologies & Outils

VMware Cisco Packet Tracer pfSense Windows Server Ubuntu Docker

Détails

  • Configuration et administration avancée d'Active Directory
  • Déploiement d'une architecture ERP distribuée :
    • Serveur front-end sous Windows Server avec IIS
    • Serveur back-end sous Ubuntu conteneurisé avec Docker pour la gestion des bases de données
  • Mise en place d'un pare-feu pfSense et d'un serveur proxy Squid pour le filtrage du trafic
  • Conception d'une politique de sauvegarde 3-2-1 et tolérance aux pannes par stockage RAID

  • Hard Skills valorisés : Sécurité des SI, Administration système, Architecture réseau
  • Soft Skills valorisés : Travail d'équipe, Communication, Vulgarisation technique, Gestion de projet
