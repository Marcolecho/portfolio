Projet Ecole Web Réseau social

Breezy

Juin 2025 - Juin 2025

Dans le cadre d'un projet école, nous avions à développer une application web de type réseau social.
Ce réseau social se devait d'être léger et réactif et devait avoir les mêmes fonctionnalités que X (Twitter) : Créer des posts courts et intéragir avec les autres utilisateurs, s'abonner, liker, notification...

Technologies & Outils

React Typescript Tailwind Mongoose/MongoDB Sequelize/MSSQL Github Docker

Détails

  • Architecture microservice
  • Respect des règles d'architectures (Model/Controller/Route/Middleware)
  • Utilisation d'ORM pour les différens services
  • Containeurisation des différents services

  • Hard Skills valorisés : Architecture logiciel, Technologies Web
  • Soft Skills valorisés : Travail d'équipe, Leadership, Communication, Vulgarisation, Gestion de projets, Gestion des conflits
