Projet École Web Réseau social

Breezy

Juin 2025

Conception et développement d'une application web de réseau social moderne, conçue pour être performante, fluide et réactive.
Inspiré de X (Twitter), Breezy propose des fonctionnalités clés d'interaction : publication de messages courts, système d'abonnements, mentions "j'aime" et gestion des notifications.
Le projet s'appuie sur une architecture microservices conteneurisée pour garantir la scalabilité et la séparation des responsabilités applicatives.

Technologies & Outils

React TypeScript Tailwind CSS Mongoose / MongoDB Sequelize / MSSQL GitHub Docker

Détails

  • Conception d'une architecture microservices modulaire
  • Mise en œuvre des bonnes pratiques de découpage (Modèle / Contrôleur / Route / Middleware)
  • Utilisation d'ORM/ODM adaptés selon les besoins des services (Sequelize et Mongoose)
  • Conteneurisation complète des différents microservices via Docker

  • Hard Skills valorisés : Architecture logicielle, Microservices, Développement Web Full-Stack, Bases de données relationnelles & NoSQL
  • Soft Skills valorisés : Travail d'équipe, Leadership, Communication, Vulgarisation technique, Gestion de projet, Gestion de conflits
