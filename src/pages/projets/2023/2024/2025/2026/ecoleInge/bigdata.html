Projet Big Data

Octobre 2026 - Octobre 2026

Dans le cadre d'un projet école en deuxième année d'école d'ingénieur, nous avons réaliser en équipe un projet autour de la Big DATA.
Le but de ce projet était d'à partir d'une source hétérogène de données (BDD,excel,txt...), rendre un dashboard powerBi permettant de faire facilement comprendre les données.
Ici, les données sont des données à caractère médical et nos clients fictifs sont différents hopitaux voulant exploiter leurs données.

Technologies & Outils

Talend Open studio for Big Data (TOSBD) HDFS Cloudera Apache Hive PowerBi

Détails

  • Extraction et transformation des données avec TOSBD
  • Chargement dans hdfs des données transformés sur une machine virtuelle cloudera
  • Création des tables et chargement des données avec Apache Hive
  • Connection aux données Hive depuis PowerBi
  • Création d'un dashboard interactif avec PowerBi

  • Hard Skills valorisés : SQL, PowerBi, Outils de BigData
  • Soft Skills valorisés : Travail d'équipe, Leadership, Communication, Vulgarisation, Pédagogie
