IA Projet Ecole

Projet IA

Mars 2026 - Avril 2026

Dans le cadre d'un projet école en deuxième année d'école d'ingénieur, nous avons réaliser en équipe un projet autour de l'IA.
Le contexte de ce projet était de réussir à travers une IA à prédire si un candidat à un poste pourrait potentiellement partir dans l'année suivante.
Pour cela, nous avions à disposition une base de données de personne contenant beaucoup de détails sur ces derniers et étant parti ou non dans l'entreprise.

Technologies & Outils

Python Streamlit

Détails

  • Respect du RGPD (diversité/équité/biais algorithmique)
  • Nettoyage des données (v. manquantes / v. abérantes / normalisation)
  • Test de plusieurs modèles (reg. log. / KNN / Arbre de décision / Random Forest)
  • Cross validation
  • Evaluation par métrique (Accuracy / F1 score / ROC AUC)
  • Choix des nettoyages, modèles et évaluation via une interface web Streamlit

  • Hard Skills valorisés : IA, Python
  • Soft Skills valorisés : Travail d'équipe, Leadership, Communication, Vulgarisation
