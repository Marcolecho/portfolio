Web Alternance Algorithmique

Osiris

septembre 2023 - aujourd'hui

Application web de planification de lots de production de l'usine (similaire à un Gantt dynamique). Cette dernière permet d'automatiser et d'optimiser le suivi de la production.
L'utilisation prévoir de mettre jour facilement le planning en cas de retard, pour ensuite permettre l'ananlyse des différentes cause de retard.
Le logiciel prévoit de créer et modifier des recettes de lots pour ensuite les lancer sur le planning. Il est possible de gérer la main d'oeuvre necessaire et possédé, la consommation et production des réservoirs, la récupération des lots à produire via SAP et encore pleins d'autres fonctionnalités.

Technologies & Outils

HTML/CSS Javascript PHP Snowflake Python Node.js Socket.io SQL Server IIS pm2

Détails

  • Développement de l'application web avec des technologies connus de tous
  • Dévelopement et optimisation d'algorithmes complexe
  • Algorithmique faite en procédures stockées SQL
  • Collecte des données SAP en passant par une API Node connecté à Snowflake
  • Aucune tolérance au bug car données sensibles
  • Présentation à l'international du logiciel

  • Hard Skills valorisés : Base de données, Conception, Optimisation, Algorithmique
  • Soft Skills valorisés : Résolution de problèmes, Relation client, Communication oral, Gestion de la pression, Anglais
