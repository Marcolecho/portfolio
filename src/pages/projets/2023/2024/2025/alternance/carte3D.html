Web Alternance 3D

Carte 3D

Mars 2024 - Juin 2024

Conception et développement d'une application web de visite immersive 3D et à 360° du site industriel Sanofi Sisteron.
La solution permet d'explorer la carte interactive des bâtiments du site et d'y pénétrer virtuellement.
Elle intègre une navigation panoramique à 360° inspirée de Google Street View ainsi qu'un éditeur d'administration dédié à la gestion de la carte et des parcours d'exploration.

Technologies & Outils

HTML/CSS JavaScript Node.js Three.js Vite Vue.js SQL Server IIS PM2

Détails

  • Développement d'un écosystème de trois applications interconnectées :
    • Application web d'exploration (carte 3D interactive & visites 360°)
    • Application web d'édition et d'administration
    • API REST centralisant les données entre la base SQL Server et les deux clients web
  • Conception d'une base de données générique et hiérarchisée assurant la scalabilité du projet
  • Conduite du projet en totale autonomie, de la collecte du besoin client jusqu'au déploiement en production
  • Déploiement et hébergement des services sur serveur Windows interne avec IIS et PM2

  • Hard Skills valorisés : Rendu 3D Web (Three.js), Architecture de bases de données, Architecture Découplée (Client/Serveur & API REST)
  • Soft Skills valorisés : Autonomie, Communication orale, Créativité, Recueil de besoins
