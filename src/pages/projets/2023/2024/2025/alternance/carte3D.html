Web Alternance 3D

Carte 3D

mars 2024 - Juin 2024

Application web de visite immersive 3D/360° du site Sanofi Sisteron.
Visualisation des bâtiments du site avec possibilité de rentrer dans ces derniers.
Visite 360° style Google Street View des bâtiments.
Editeur de la carte et des visites 360°.

Technologies & Outils

HTML/CSS Javascript Node.js Three.js Vite Vue.js SQL Server IIS pm2

Détails

  • Réalisation de trois applications différentes travaillant ensemble
    • Application web contenant la carte 3D et la visite 360°
    • Application web Vite + Vue.js + Node.js
    • API Node.js connecté à la base de données et aux deux applications web
  • Architecture de la base de données générique et hiérarchisée prévoyant l'évolution future du projet
  • Projet réalisé en totale autonomie, du recueil de besoin jusqu'à la livraison du produit
  • Mise en ligne des applications sur un serveur windows interne avec IIS et pm2

  • Hard Skills valorisés : Base de données, Architecture Back/Front séparé
  • Soft Skills valorisés : Autonomie, Communication, Présentation, Créativité
